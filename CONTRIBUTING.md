# Contributing

Bibliognost is presently in private testing. Please use the GitHub issue templates for reproducible bugs and focused feature requests.

Before proposing code changes:

1. Build the Release configuration successfully.
2. Test the affected workflow in-game with the current Dalamud API.
3. Never commit credentials, browser cookies, API keys, downloaded mod packages, or user configuration.
4. Preserve explicit confirmation for downloads, imports, and update actions.
5. Describe any provider markup or API assumptions in the pull request.

AI assistance used in a contribution must be disclosed honestly wherever the destination repository or Dalamud submission policy requires it.
